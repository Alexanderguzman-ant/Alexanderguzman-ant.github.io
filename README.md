# Portafolio — Alexander Guzmán Yañez

Sitio estático (HTML/CSS/JS, sin servidor ni build) con mi presentación profesional
y el caso de estudio etnográfico sobre situación de calle e intervención social municipal.

## Estructura

```
├── index.html                 # Inicio, sobre mí, proyectos, contacto
├── caso-situacion-calle.html  # Caso de estudio con carrusel de 13 láminas
├── styles.css                 # Estilos compartidos
└── img/                       # Fotografías de terreno (rostros difuminados)
```

## Publicación

El sitio es 100% estático: basta servir la carpeta tal cual.
Está pensado para GitHub Pages (`usuario.github.io`), pero funciona en
cualquier hosting estático (Netlify, Cloudflare Pages, etc.).
